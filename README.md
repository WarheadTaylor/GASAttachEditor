# GAS Attach Editor - Unreal Engine Plugin
Editor Window with similar (and additional) functionality to UE command-line `ShowDebug AbilitySystem`.

This fork of the plugin adds some extra features and formatting updates to the original plugin found [here](https://github.com/Monocluar/GASAttachEditor).

### New Features:
- Support for newer version of Unreal Engine (5.4+)
- Text formatting for better readability
- Attribute base values in Attributes editor window
